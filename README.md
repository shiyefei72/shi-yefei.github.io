## 🔬 主要研究方向

**基于谱元法与人工智能的强地面运动模拟与地形放大效应研究**

以**谱元法（SPECFEM3D）**三维数值模拟为核心手段，结合**人工智能 / 深度学习**方法，开展复杂地形条件下的**强地面运动模拟与地震动场预测**，并利用**遥感与 GIS** 手段对模拟结果进行地形放大效应的空间验证。研究工作依托国家超级计算平台（如国家超级计算长沙中心）完成大规模并行计算。

细分方向：
- 强地面运动数值模拟（谱元法 SEM / SPECFEM3D、宽频带地震动模拟、超算并行计算）
- AI 与地震动交叉（深度学习地震动预测、波形生成、地震预警）
- 地形放大效应与遥感验证（遥感 / GIS 空间分析、震害与滑坡交叉验证、地震危险性评估）
- 遥感与多源时空数据（LiDAR、高光谱、无人机遥感，多源数据融合）
